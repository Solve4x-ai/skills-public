# Security

## Reporting a problem

If you find a security problem in {{NAME}}, please tell us privately instead of opening a public issue:

- use GitHub's **Report a vulnerability** button on this repo's **Security** tab, or
- contact the owner, {{OWNER}}, directly.

Say what you found, how to reproduce it, and what could happen. We'll reply as soon as we can and keep you posted until it's fixed.

## Secrets

This repo never holds passwords, keys or tokens. If one gets committed by accident, it's treated as exposed: it's changed (rotated) first, then removed from the code.
